# Aaditi Gabale — Portfolio

A responsive React portfolio built with Vite, plain CSS, and Lucide icons. The design uses a minimal premium light theme with blue accents.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Production build
```bash
npm run build
npm run preview
```

## Customize
- Main content, project cards, skills, and links: `src/App.jsx`
- Colors, typography, layout, and responsive styles: `src/styles.css`
- Page title and description: `index.html`

## Notes
- The project descriptions intentionally distinguish completed work from ongoing concepts.
- The contact email opens the visitor's default email app.
- Social links open GitHub and LinkedIn in a new tab.
- Google Fonts are loaded remotely; the page falls back to system sans-serif fonts if unavailable.
